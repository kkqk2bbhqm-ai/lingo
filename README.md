> 物联网工程｜运筹优化建模基础示例项目

本项目整理LINGO基础建模例题，演示集合定义、向量赋值、内置函数`@abs`、`@smin`、`@smax`的使用，学习区分已知常量与待求解决策变量。
这类优化模型可以迁移应用在物联网场景：设备资源调度、储能容量规划、网络节点负载优化等工程问题。

## 案例清单
- Example4：文字型集合，定义多属性变量
- Example5：部分数据固定，其余变量作为决策变量
- Example6：向量求最小值、最大值
- exercise_abs：向量元素绝对值计算

## 运行环境
LINGO 18

## 核心知识点
1. LINGO代码固定结构：`sets` → `endsets` → `data` → `enddata` → 计算公式 → `end`
2. 两类集合定义：数字下标集合 / 文本成员集合
3. 内置函数：`@abs()`绝对值，`@smin()`最小值，`@smax()`最大值
4. 区分data中**固定常数**与未赋值**决策变量**
5. 变量边界约束函数：`@free()`、`@bnd()`

## 踩坑记录
LINGO只接受英文半角符号；中文标点会触发 Error 11 语法错误。
例5教材原版逗号占位写法在老版本LINGO会报错，仓库提供兼容稳定版本。
